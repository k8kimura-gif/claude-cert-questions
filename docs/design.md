# Claude 資格対策 出題アプリ 設計

## 1. 対象試験と前提

数値は第三者の対策サイト経由で確認したもの。CCDV-F は Anthropic の公式 Exam Guide(2026年7月版)の値とされるが、Architect の配点は公式には非公開で未確認。

| | Developer – Foundations (CCDV-F) | Architect – Foundations (CCAR-F) |
|---|---|---|
| 問題数 | 53問 | 60問(未確認) |
| 時間 | 120分 | 120分 |
| 形式 | 単一選択 + 複数選択(選ぶ個数は問題文に明記) | シナリオベースの4択。6シナリオ中4つが出題されるとの情報あり |
| 合格点 | スケールドスコア 720 / 1000 | 720 / 1000 |

出題ドメインと配点:

| Developer | 配点 | 模試での問題数 |
|---|---|---|
| Applications and Integration | 33.1% | 18 |
| Model Selection and Optimization | 16.8% | 9 |
| Agents and Workflows | 14.7% | 8 |
| Prompt and Context Engineering | 11.0% | 6 |
| Tools and MCPs | 10.6% | 6 |
| Security and Safety | 8.1% | 4 |
| Claude Code | 3.1% | 1 |
| Eval, Testing, and Debugging | 2.6% | 1 |

| Architect | 配点(未確認) | 模試での問題数 |
|---|---|---|
| Agentic Architecture and Orchestration | 27% | 16 |
| Claude Code Configuration and Workflows | 20% | 12 |
| Prompt Engineering and Structured Output | 20% | 12 |
| Tool Design and MCP Integration | 18% | 11 |
| Context Management and Reliability | 15% | 9 |

配点・問題数・時間は `exams/*.json` に設定値として持ち、公式ガイドが改訂されたらそこだけ直す。

## 2. 全体構成

バックエンドを持たない静的 PWA と、リポジトリ内の問題バンク(JSON)の2つで構成する。

```
claude-cert-questions/
├── exams/
│   ├── developer.json        # 試験定義: ドメイン、配点、問題数、制限時間
│   └── architect.json
├── questions/
│   ├── developer/<domain>.json
│   └── architect/
│       ├── scenarios.json    # シナリオ本文
│       └── <domain>.json     # 各問題は scenarioId を持つ
├── index.html, app.js, styles.css, sw.js   # PWA 本体。ビルド不要の静的ファイル
├── scripts/validate.mjs      # 問題バンクのスキーマ検証(CI で実行)
└── .github/workflows/pages.yml    # 検証して GitHub Pages へデプロイ
```

- PC はブラウザ、iPhone は Safari で「ホーム画面に追加」して使う。Service Worker で問題をキャッシュし、オフラインでも解ける。
- 問題の追加は JSON を足して push するだけ。アプリは次回起動時に新しい問題を取り込む。

## 3. 問題データ

```json
{
  "id": "dev-tools-0012",
  "cert": "developer",
  "domain": "tools-and-mcps",
  "type": "single",
  "scenarioId": null,
  "stem": "問題文",
  "choices": [{ "id": "a", "text": "…", "why": "この選択肢が正しい/誤りである理由" }],
  "answer": ["b"],
  "explanation": "全体の解説",
  "refs": ["https://docs.claude.com/…"],
  "difficulty": 2
}
```

- `type` は `single` / `multi`。`multi` は「2つ選べ」のように個数を問題文に含める。
- `cert` を問題側に持たせ、読み込み時にモードと一致しないものは弾く。2資格の問題が混ざらないことをデータとコードの両方で保証する。
- 問題は公式 Exam Guide のドメインと公式ドキュメントを根拠に Claude Code で自作する。市販の問題集や実際の試験問題は写さない。`refs` に根拠ページを必ず付け、解説から原典に飛べるようにする。
- 問題文・選択肢・解説はすべて日本語で書く(本番も日本語版を受験するため)。API 名、パラメータ名、製品名などの固有の用語は英語表記のまま残す。
- 現状は各資格 200問。Architect は 6 シナリオに各 33〜34問あり、模試は 4 シナリオから 15問ずつ、計 60問を出す。

## 4. アプリのモード

起動直後に資格を選ぶ(Developer / Architect)。選択はヘッダーに常時表示し、成績・復習キュー・模試履歴もすべて資格ごとに別の保存領域に分ける。

| モード | 内容 |
|---|---|
| ひたすら解く | 1問ずつ出題。回答するとその場で正誤と解説(選択肢ごとの理由、根拠リンク)を表示し、次の問題へ。終了操作をするまで続く。ドメイン絞り込みと「苦手優先」を選べる |
| 今日の問題 | 試験日から逆算した量をその日の分として出す(4.1) |
| 復習 | 間違えた問題と、間隔反復で期限が来た問題だけを出す |
| 模擬試験 | 本番と同じ問題数・制限時間・ドメイン比率。回答中は正誤も解説も出さない。見直しフラグ、問題一覧からのジャンプ、残り時間表示、中断再開あり。Architect はシナリオ 6つから 4つを選び、シナリオ単位でまとめて出題する |
| 成績 | ドメイン別正答率、模試の履歴、推移 |

出題の選び方:
- ひたすら解くモードは、未出題 → 期限切れの復習 → 正答率の低いドメイン、の順に重み付けして抽選する。
- 模試の結果は正答率とドメイン別内訳で示す。スケールドスコアへの換算式は非公開なので 720点相当かどうかは出さず、目安として正答率 75% 以上を合格圏と表示する。

### 4.1 1日の出題量

資格ごとに、その日最初にアプリを開いた時点で決める。

- 新規: 未着手の問題数 ÷(試験日までの日数 − 2)。直前の 2 日は模試と復習に充てる
- 復習: 期限が来た問題すべて。間隔は、不正解なら翌日、正解が続くごとに 3日、7日、14日
- 直近 30 回の正答率が 85% 以上なら新規を 1.25 倍にする。60% 未満なら苦手な問題を 5問足す
- 合計が 5問に満たない日は 5問まで補う

試験日は設定画面で資格ごとに変えられる。初期値は 2026-12-05。

## 5. 定期出題

3系統を用意する。A と B は同じ出題手順書 `docs/quiz-prompt.md` を読んで動くので、どちらを使っても出題の仕方は変わらない。手順書には、資格を混ぜないこと、1問ずつ出して回答を待つこと、回答後に解説と根拠リンクを示すことを書く。

**A. Meta Muse の定期タスク**
Muse に GitHub アカウントを接続し(GitHub App「Meta Muse AI」。非公開リポジトリも対象にできる)、毎日決まった時刻の定期タスクを登録する。タスクは問題バンクから数問を選んで出題し、iPhone の Muse アプリで回答すると解説を返す。資格ごとにタスクを分ける(Developer 用、Architect 用)。Muse 側の仕様は公式ドキュメントで確認できていないため、接続と定期タスクの挙動は設定時に実機で確かめる。

**B. Claude のスケジュール実行**
クラウドのルーティンをこのリポジトリに接続し、同じ手順書で出題する。iPhone の Claude アプリでセッションを開いて回答する。

これとは別に週1回、公式ドキュメントの更新を見て新しい問題を作り、PR として出すルーティンを Claude 側に置く。リポジトリへの書き込みはこのルーティンだけが行い、Muse には読み取りだけを許可する。

**C. PWA の「今日の問題」(補助)**
iPhone のリマインダーやカレンダーの繰り返し予定にアプリの URL を貼る。Claude 側の通知に依存せず、オフラインでも動く。

iOS の PWA からのプッシュ通知はバックエンドが必要になるため作らない。

## 6. 学習記録の保存

- 端末内の localStorage に資格ごとに保存する(回答履歴、復習スケジュール、模試の途中経過)。
- PC と iPhone の同期は初版では行わず、設定画面で記録を文字列として書き出し、別の端末で読み込む。
- 同期が必要になったら、ユーザー本人の GitHub Gist を保存先にする方式を後から足す。

## 7. 実装順

1. 試験定義、問題スキーマ、検証スクリプト
2. PWA 本体: 資格切り替え、ひたすら解くモード、解説表示
3. 模擬試験モード、成績画面
4. 復習(間隔反復)、今日の問題
5. 問題バンクの作成(各資格 150問)
6. GitHub Pages へのデプロイ、iPhone での動作確認
7. 出題手順書の作成、Muse / Claude の定期出題と問題追加ルーティンの設定

## 8. 残っている作業

- 誤答の選択肢の質を上げる。長さの偏りは緩和したが、正解が最も短い選択肢になる問題はほぼなく、明らかに誤りと分かる短い誤答も残っている
- 問題の内容を、公式の試験ガイドと 1 問ずつ突き合わせる
- Muse の定期タスクを登録する(`docs/muse-setup.md`)
- 問題を自動で追加する Claude のルーティンを設定する
